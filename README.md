# ХЛЕБНО — существующий прототип

## Страницы
- index.html — главная; прежние разделы сохранены.
- bread.html — каталог «Хлеб», один фирменный продукт.
- karavay-1.html — подробная карточка «Каравай № 1».

## Данные и расширение
shop-data.js содержит ассортимент и независимые варианты веса. Для нового вида хлеба добавьте объект с variants и url. Сейчас у «Каравая № 1» два веса (500 и 900 г), подтверждённые владельцем цены: 500 г — 189 ₽, 900 г — 279 ₽, остаток каждого веса — 10 шт., available:true. Настройка slicingEnabled у каждого веса отдельная. Чтобы разрешить покупку, одновременно требуются утверждённая положительная цена, available:true и целый положительный stock. Серверных заказов и оплаты нет. Перед реальной продажей эти проверки нужно повторять на сервере.

## Корзина
shop.js — общая корзина для главной и новых страниц. Вес и нарезка образуют отдельную позицию. Остаток общего веса учитывается суммарно для нарезанного и целого хлеба. В localStorage браузера сохраняются только идентификаторы товара, варианта, способ нарезки и количество. Цены берутся из текущего справочника; устаревшая или недоступная позиция исключается из суммы. Персональные сведения не собираются. Доступ к localStorage может быть запрещён браузером: в таком случае корзина работает в памяти вкладки.

## Изображения
Основное изображение создано ИИ по предоставленной фотографии, не является документальным снимком. Второе — ранее созданный эскиз нарезки с отличающимся рисунком корки, это явно обозначено. Третий слот — честная заглушка для реального крупного плана. Заменить пути и подписи можно в gallery товара. Старые временные фотографии других разделов не заменены.

## Контент
Полное описание, состав, аллергены, условия хранения и сочетания предоставлены владельцем. Пищевая ценность не утверждена: таблица на 100 г без вымышленных чисел. Срок годности не указан до подтверждения производственной документацией.

## Проверка
Без установки зависимостей: npm test или node tests/cart.test.cjs. Проверки используют отдельный набор тестовых цен и остатков только в памяти и не меняют данные страницы. Дополнительно проверены синтаксис JS, ссылки на файлы, синхронизация dist и сохранение содержимого остальных разделов главной.

## Просмотр и размещение
Файлы dist — готовая статическая версия. Обновление закрытого сайта согласовано владельцем. Встроенный sites-preview не смог открыть браузерный порт: relay readiness timeout. Поэтому переключатели и мобильная вёрстка в настоящем браузере на этом этапе не проверены. Доступ к закрытому сайту остаётся только у владельца.

## Интерактивные варианты каравая
Выбор веса и нарезки оформлен одинаковыми компактными карточками с фирменными SVG-пиктограммами. Это декоративные иллюстрации, не фотографии товара. Выбор отмечается aria-pressed, рамкой и галочкой; мышь не обязательна. После успешного cart.add модуль purchase-feedback.js показывает галочку и «Добавлено» на 1,4 секунды, блокируя повторное нажатие. При изменении выбора подтверждение сбрасывается. Недоступный или неоценённый вариант не добавляется и не вызывает ложного подтверждения.

Звук изначально выключен при каждом открытии страницы. Переключатель не создаёт звук сам по себе. После успешного нажатия покупки Web Audio синтезирует тихий сигнал длиной 0,18 секунды; чужие записи не используются. Отказ AudioContext не мешает добавлению. Отрисовка учтёт prefers-reduced-motion.

Проверки: 30 для корзины, 19 для обратной связи/звукового графа с моками, 19 интеграционных для настоящих обработчиков выбора и покупки в адаптере DOM. Тестовые цены используются только в изолированной памяти теста. Внешний вид в мобильном браузере и фактическое воспроизведение устройством ещё не проверены: инструмент управления браузером недоступен. Обновление закрытой версии с интерактивными элементами согласовано владельцем.

Цены каравая 189 / 279 ₽ и остатки 10 шт. на каждый вес подтверждены владельцем. Остатки — настройки демонстрационного каталога, не серверный склад. Реальные заказы и списание остатков не подключены.

## Каталог и иллюстрация нарезки
Каталог содержит статическую карточку каравая на случай задержки JS. Пространство рядом занимает интерактивная SVG-иллюстрация нарезки с кнопкой воспроизведения и ползунком. Это рисунок, не реальная съёмка. При prefers-reduced-motion кнопка переключает финальные состояния без автоматического движения. Иллюстрация не меняет выбор нарезки и корзину; для заказа перейдите к товару. Проверки: node tests/slicing.test.cjs.
